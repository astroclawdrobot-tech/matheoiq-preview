# MatheoIQ Médico Móvil Command Hub

Preview statique safe pour le hub opérationnel MatheoIQ Médico Móvil.

- Ne contient aucune donnée patient réelle.
- Ne contient aucun secret.
- Ne déclenche aucun dispatch/paiement/envoi live.
- Clone le pattern de command hub observé dans `alma-fina-b2b-command-hub`, mais sans contenu Alma Fina.
- Sert de prototype pour: clinics connectées, queue demandes, médecins vérifiés, dispatch IA, escalations.

## Déploiement preview

Ouvrir `matheoiq-command-hub/index.html` ou depuis `web-prototypes/index.html`.
